◆ LIST_BLOCK_INIT_CAP

#define LIST_BLOCK_INIT_CAP   8

A header that generates typed doubly linked lists, Uses macros to describe list element type. These macros must be defined: LIST_ELEM - type to use for list elements LIST_T - name for list struct. LIST_F(name) - func/var name generator in list namespace. LIST_FMT - list element format specifier/string, unless LIST_REF. LIST_REF - optional, pass elements by pointer instead of by value.

Use LIST_IMPL macro in one TU where you want a list type to be implemented.

Lists are implemented as struct with backing store for nodes and a header. Header contains pointers to head, tail and free nodes.

All allocated, but not live (free) nodes are chained in their own linked list.

Backing store is organized as vector of chunks (blocks) of nodes. Each chunk has its own capacity and is never reallocated. Chunk struct stores its flexible array inline instead of allocating separately. Their individual capacities grow geometrically with every new chunk.

Initial state of the list is NULL-ed header and 0 blocks. First element added will add a new block of initial capacity, then take first free node from that block, copy passed value to that node, then add it to the back of the list.

Whenever there's no free nodes left and a new element needs to be added, a new block is reserved. Capacity of that block is double the capacity of previously allocated block. After allocating the new block, all nodes in it are linked in one direction, then front of this chain becomes the next free node.

Whenever a new element needs to be added in the middle, a node is popped from the front of free nodes chain, and linked between two live nodes of the list.

First node always has prev set to NULL, last node has next set to NULL.

Clearing the list means linking nodes throughout all blocks into free nodes chain, setting tail and head to NULL, and hdr.free points to the first free node.

Freeing the list means freeing all blocks, freeing block pointers vector and NULL-ing the list header. Capacity of the first block of nodes.
