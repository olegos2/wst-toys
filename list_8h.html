Detailed Description

Type-safe doubly linked lists backed by geometric node blocks.

Live nodes are linked through next/prev; removed nodes form a singly linked free pool inside the node blocks. Blocks are allocated on demand and never resized, so node addresses stay stable across insertions. Public operations cover lifecycle, node-handle access and mutation, index/value access, and tail append/pop.

Provided stamps:

  • int: WstListInt, wst_list_int_*

Every operation verifies the block-pointer vector, reporting WstListErr. Node pointers are invalidated by list_free and become stale after list_clear.
