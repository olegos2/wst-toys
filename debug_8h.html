◆ wst_log_graphviz()

const char * wst_log_graphviz ( const char *  dot_source,
const char *  name 
)

Render Graphviz dot_source into an SVG next to the current log.

Writes <name>.dot and <name>.svg through the reusable Graphviz module. Names are sanitized and made unique. The returned file name is relative to the log directory, owned by the logger, and valid until the next Graphviz call or wst_log_close. Returns NULL when no log directory is open or Graphviz fails.

◆ wst_log_open()

bool wst_log_open ( const char *  log_dir,
WstLogFormat  format 
)

Open a new log in log_dir.

The directory is created if needed, but its parents must already exist, and a timestamped file is opened inside it. WST_LOG_FORMAT_HTML enables images.

When log_dir is NULL, logs go to stderr in text mode, requesting HTML falls back to stderr text.

Opening a log closes the previous one. Logs are closed automatically at exit, so calling wst_log_close is optional.
